RCUT 2.5 PR1.0.1 - Bug Fix Report

Summary

This patch resolves a critical issue affecting the shared library (DLL) build of RCUT. The static library (libRCUT.a) was unaffected.

Fixed

DLL export of input functions

Issue

When RCUT was built as a DLL, several public API functions declared in RCUT.h were not being exported by libRCUT.dll. Applications linking against the generated import library (libRCUT.dll.a) therefore failed during linking with unresolved external symbol errors.

A notable affected function was:

  • RCUT_Input_GetMouseDeltaX()

The implementation existed within the library and compiled correctly, but the symbol was absent from the DLL export table.

Cause

The affected implementation source file did not include the public RCUT.h header containing the RCUT_API export/import macro. As a result, the function definitions were compiled without __declspec(dllexport) when building the shared library, preventing them from being exported.

Resolution

  • Updated the implementation to use the public API declarations provided by RCUT.h.
  • Removed duplicate declarations that bypassed the RCUT_API export macro.
  • Rebuilt both the DLL and import library.

Verification

The fix was verified by:

  • Successfully exporting RCUT_Input_GetMouseDeltaX from libRCUT.dll.
  • Successfully generating a valid libRCUT.dll.a import library.
  • Successfully linking external applications against the DLL.
  • Confirming that both static and shared library configurations build successfully using CMake.

Impact

  • Shared Library (libRCUT.dll): Fixed.
  • Import Library (libRCUT.dll.a): Fixed.

No API changes were introduced. Existing source code remains compatible.
