RCUT, the Rendering Core Utility Toolkit, is a collection of libraries
developed by GPSoftware to render graphics across a wide range of dimensions.
As of September 2026, the project is planned to support 2D, 2.5D,
and 3D graphics. The 2.5D implementation currently uses a DDA engine in
v1.0.0, although we plan to upgrade it to a BSP engine.
