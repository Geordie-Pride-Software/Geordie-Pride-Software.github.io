About the toolkit

A foundation for every dimension

RCUT is GPSoftware’s rendering foundation: a family of focused libraries designed to make graphics development more consistent across different dimensions and project types.

Its roadmap covers 2D, 2.5D, and 3D graphics. The current 2.5D renderer uses a DDA engine in version 1.0.0, with a future BSP implementation planned to support richer scene construction.

Current scope

2D / 2.5D / 3D 2.5D engine available in v1.0.0
