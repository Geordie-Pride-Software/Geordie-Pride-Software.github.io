RCUT2.5-PR1.0.0

This release contains the first fully functional RCUT 2.5 DLL, based on the original DDA raycasting engine.

Current Status

Basic texture support is included in this release; however, it is still considered experimental. While the implementation is present, it has not yet been fully tested, and additional validation is required before it can be considered production-ready.

End of Development for PR1.0.0

This release marks the completion of RCUT2.5-PR1.0.0. Future development, feature additions, bug fixes, and subsequent releases will be published through the GP Software repository as RCUT continues to evolve as a product of the Solar Project.
